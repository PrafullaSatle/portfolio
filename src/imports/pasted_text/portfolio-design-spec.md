# Personal Portfolio Website — UI/UX Design

Design a clean, modern, professional personal portfolio website for an undergraduate engineer specializing in **Artificial Intelligence & Data Science**.

The website is primarily intended for **job applications and recruiters**. It should communicate technical ability, projects, experience, and skills clearly without looking overly flashy or like a startup landing page.

## Overall Design

* Minimal and professional
* Modern but not excessive
* Strong typography and clear visual hierarchy
* Plenty of whitespace
* Responsive design for desktop, tablet, and mobile
* Subtle animations/micro-interactions can be suggested, but avoid excessive effects
* Avoid unnecessary 3D graphics, gradients, glassmorphism, or complicated visual effects
* Prioritize readability and fast navigation

## Navigation

Create a simple sticky navigation bar:

* Home
* About
* Projects
* Skills
* Experience
* Certifications
* Resume
* Contact

Include a clear **View Resume** button.

## Hero Section

Create a concise hero section.

Include:

**Name:** Prafulla Satle

**Headline:** AI & Data Science Engineer

**Short introduction:**
"Engineer focused on AI, Data Science, Data Analytics, and practical software development."

Include two primary actions:

* View Projects
* Download Resume

Also include subtle links/icons for:

* GitHub
* LinkedIn
* Email

Do not use exaggerated statements such as "AI expert", "future billionaire", "10x developer", etc.

## About Section

Create a short professional introduction.

Include:

* Engineering background
* AI & Data Science focus
* Interest in Data Analytics, AI/ML and software development
* Practical project-building experience
* Current career objective

Keep the content concise.

Include a small "What I Work With" visual grouping rather than a giant list of technologies.

## Projects Section

This should be the most important section of the website.

Design reusable project cards.

Each project card should contain:

* Project thumbnail/screenshot
* Project title
* One-line description
* Technology tags
* Project category
* GitHub button
* Live Demo button where available

Add project filtering:

* All
* AI / ML
* Data Analytics
* Web Development
* Other

Create a detailed project view/modal/page containing:

* Project overview
* Problem
* Approach
* My contribution
* Technologies
* Key features
* Screenshots
* Results/output
* GitHub link
* Live demo link

The design must support adding **new projects later without redesigning the website**.

## Project Visuals

Design project cards assuming that screenshots will be used as the primary visual evidence.

Do not use generic stock photos.

For projects such as data analytics or machine learning, allow visuals such as:

* Dashboards
* Charts
* Model results
* Data visualizations
* Output screenshots

## Skills Section

Organize skills into meaningful categories rather than displaying one huge wall of logos.

Categories:

**Programming & Data**

* Python
* SQL
* Pandas
* NumPy
* Scikit-learn

**Web Development**

* HTML
* CSS
* JavaScript
* Tailwind CSS
* React

**Tools & Platforms**

* Git
* GitHub
* VS Code
* Jupyter
* AWS

Show proficiency through clean tags or grouped cards.

Do NOT use percentage-based skill bars such as "Python — 95%".

## Experience Section

Create a clean timeline/card-based section for:

* Internships
* Training
* Major project experience
* Relevant practical experience

Each entry should contain:

* Organization
* Role
* Duration
* Short description
* Key responsibilities

Keep it concise.

## Certifications Section

Create compact certification cards.

Each card should contain:

* Certification name
* Issuing organization
* Date/year
* Credential link if available

## Resume Section

Create a dedicated but compact section encouraging recruiters to view/download the resume.

Include:

**"Want the complete picture?"**

Buttons:

* View Resume
* Download Resume

## Contact Section

Create a simple professional contact section.

Include:

* Email
* LinkedIn
* GitHub

Optionally include a simple contact form, but do not make it the focus.

## Footer

Include:

* Name
* Short role description
* GitHub
* LinkedIn
* Email
* Copyright

Keep it minimal.

## Important UX Requirement

The website should be designed as a **maintainable portfolio system**, not a one-time static presentation.

Project cards should follow a consistent reusable structure so that new projects can easily be added later.

The design should also accommodate projects with:

* GitHub only
* GitHub + Live Demo
* Screenshots
* Videos/GIFs
* Data dashboards
* Different numbers of technologies

## Visual Direction

Use a restrained professional color palette.

Suggested direction:

* Light background
* Dark text
* One primary accent color
* Subtle borders
* Moderate corner radius
* Clean sans-serif typography

The final design should feel like:

**"A capable engineer presenting real work"**

rather than:

**"A designer showing off a website."**

Create the complete desktop homepage first, followed by responsive mobile layouts.

Also create a reusable **Project Card component** and **Project Detail layout** in Figma so the design system is ready for future projects.
